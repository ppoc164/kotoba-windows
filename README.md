# Kotoba · 逐句听

Windows 本地音频转写和逐句播放应用。不需要 API 密钥，不上传音频。

完整中文使用说明及数据保存位置见 [Kotoba使用说明.txt](Kotoba使用说明.txt)。

## 使用

双击 `start.cmd`；打包后也可直接运行 `dist-v6/Kotoba/Kotoba.exe`。复制到其他电脑时请复制整个 Kotoba 文件夹。

1. 导入音频，选择语言（中文、日语、英语、韩语或自动检测）。
2. 选择模型，点击“开始本地转写”。首次使用所选模型需联网从 Hugging Face 下载，以后优先读取本地缓存。
3. 每句默认遮挡：左侧播放按钮只播放，点击遮挡处或“显示文本”才揭晓，再点可遮挡。取消勾选“遮挡文本”可显示全部文本。
4. 选择“连续播放整段”并点击播放，从当前位置播放至音频末尾，自动标出当前句子；单句模式在句末暂停，也可开启单句循环。
5. 可点击进度条任意位置或拖动滑块。拖动时显示目标时间，松开后跳转；原先暂停则继续暂停，原先播放则继续播放。自由跳转自动切换为连续播放。
6. 左侧历史可搜索和打开以前的转写，关闭或切换音频时保存播放进度；重新打开时恢复进度并默认遮挡文本。历史保存在 `程序旁的 data/history`，音频本身不会复制。原音频缺失时仍能查看、导出文本。
7. 旧版 `.kotoba.json` 记录可通过“导入旧版转写记录”多选导入，或重新导入原音频自动迁移；不需要再次识别。支持搜索句子、导出 TXT 或 SRT。
8. 音频标题旁点击“收藏”，可收藏到未分类、新建分类或移动到已有分类。左侧下拉框筛选全部音频、全部收藏或某个分类。“分类”按钮可新建分类；选中具体分类后还可重命名或删除分类，删除后收藏保留在未分类。
9. 标题旁点击“重命名”，修改应用内显示名称，原文件名不变。历史列表也可右键重命名、收藏或移动分类。分类、收藏和名称自动保存，复用已有历史数据。
10. 点击“全文预览”集中查看带时间戳的所有句子，搜索关键词后用“上一处 / 下一处”或 Enter 循环定位。点击句子会返回练习界面并跳到对应音频位置；勾选“定位后立即播放”可直接试听。预览不会改变练习界面的文本遮挡状态。

模型缓存位于 `程序旁的 data/models`。base 是默认轻量模型，small 更耗时、内存更高，tiny 适合快速试用。不要求独立显卡。首次模型下载可能较慢；如果网络无法访问 Hugging Face，下载会失败，可恢复网络后重试。

分句使用识别标点、词级时间戳和超过一秒的停顿；超过 22 秒的连续文本会拆段。自动转写、句界和时间戳可能有误差，尤其是噪声、多人重叠或无标点音频。取消操作在当前下载或推理步骤完成后生效。

## 开发

Python 3.12，运行 `setup.cmd` 安装依赖并启动。运行 `build.cmd` 打包 Windows 程序。运行 `.venv/Scripts/python.exe -m unittest -v` 检查分句和字幕格式。

`av==16.1.0` 固定为与 faster-whisper 1.2.1 兼容的版本，避免新版本移除 `metadata_errors` 参数导致转写失败。运行 `.venv/Scripts/python.exe decoder_check.py` 验证实际 WAV 和 MP4/AAC 解码；打包后运行 `verify_build.ps1` 验证可执行程序的界面、依赖和解码流程。

本地识别基于 [faster-whisper](https://github.com/SYSTRAN/faster-whisper)，界面和播放使用 PySide6/Qt。依赖与模型有各自的许可证，分发时需保留相应许可说明。
